✨ Features

Alles, was die README verspricht, auf den Punkt.

🌍 Global Intelligence

120 MCP-Tools über 30+ Domänen: 📈 Finanzmärkte, 💼 SEC-Filings, ⚔️ Konflikte, 🛩️ Militär-Flüge, 🌋 Erdbeben & Brände, 🦠 Cyber-Threats, 📰 News, 🗺️ Geospatial-Daten.

🔌 MCP via mcpo

Der stdio-MCP-Server wird über mcpo als HTTP/OpenAPI-Endpoint auf :8030 exponiert. OpenAPI-Doku unter /docs, Beschreibung unter /openapi.json. Optional per MCP_API_KEY geschützt.

📟 Ops-Center-Dashboard

Leaflet-Map mit umschaltbaren Layern (Quakes, Military, Conflict, Fires, Convergence, Nuclear, Infrastructure), 47 Live-SSE-Feeds, HUD-Bar und Circuit-Breaker-Health pro Quelle — auf :8501.

🗃 Qdrant Vektor-Store

Semantische Suche über angesammelte Intelligence („Militäraktivität nahe Taiwan"). Optionaler Qdrant-Service über das Compose-Profil vector, Collector-Daemon befüllt den Store im 5-Min-Intervall.

🚀 Portainer + GHCR

Published als ghcr.io/jbkunama1/hai.worldintelmcp:latest, deploybar als Stack direkt aus dem Repository — inkl. Volume für Cache, Reports und Vektor-Store-Daten.

🔐 Sicherheit

Keine externen API-Keys nötig — alle Quellen öffentlich. MCP_API_KEY schützt den Endpoint als Bearer-Token, TruffleHog scannt jeden Push auf versehentlich eingecheckte Secrets.

🚀 Installation

Drei Wege — Portainer ist der schnellste.

  1. Portainer: Stacks → Add stack → Repository
  2. Repository-URL: https://github.com/jbkunama1/hAI.WorldIntelMCP.git
  3. Compose-Pfad: docker-compose.yml · Branch: main
  4. Umgebungsvariablen setzen — mindestens MCP_API_KEY 🔑
  5. Deploy — das GHCR-Image wird automatisch gepullt 🎉
# Docker-Netzwerk (falls nicht vorhanden)
docker network create highfishNetwork

# Oder komplett per docker run:
docker run -d --name world-intel-mcp \
  -p 8030:8030 -p 8501:8501 \
  -v ./data:/data \
  -e MCP_API_KEY=ChangeMe \
  ghcr.io/jbkunama1/hai.worldintelmcp:latest

💡 Upstream-Version pinnen beim Selbstbauen: docker build --build-arg WORLD_INTEL_REF=v0.3.0 -t hai.worldintelmcp .

🔌 MCP-Clients anbinden

mcpo exponiert jedes Tool als eigenen HTTP-Endpunkt — OpenAPI-Doku unter /docs, Beschreibung unter openapi.json.

{
 "mcpServers": {
 "world-intel": {
 "name": "World Intel MCP",
 "type": "streamable",
 "url": "http://world-intel-mcp:8030",
 "enabled": true
 }
 }
}

🔐 Mit gesetztem MCP_API_KEY senden Clients Authorization: Bearer <KEY>. Das Dashboard (:8501) hat keine eigene Auth — nur im LAN oder hinter Cloudflare Tunnel betreiben.

# CLI direkt im Container:
docker exec -it world-intel-mcp intel markets
docker exec -it world-intel-mcp intel earthquakes --min-mag 5.0
docker exec -it world-intel-mcp intel status
